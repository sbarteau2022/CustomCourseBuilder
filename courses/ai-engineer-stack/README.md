## What makes this different from a cert list

1. **The ethics spine.** Every week, one sealed three-tier observer reading: what is
   materially true, what the field suppresses, and the question you can't unknow. Each unit
   in `course.ts` carries its own reading of its own subject — the ML unit reads the labor
   behind the labels; the cloud unit reads dependency sold as elasticity; the responsible-AI
   unit reads the fact that its own certificate is issued by a hyperscaler.

2. **The build spine.** The applied thread of every unit is Elle herself: the ingestion
   pipeline (Track C), the API and surface (Track A), the RAG and model layer (Track B), the
   venture around it (Track D), the legal ground under it (Track E). No toy projects.

3. **The witness spine.** Each unit publishes an adaptation contract — pacing envelope,
   watch-for signals, accelerate/reinforce/reroute moves — and Elle executes it in real
   time. The adaptation log is reviewed with the learner at each phase boundary.

4. **The credential.** 74 sealed readings (48 weekly + 18 unit syntheses + 4 phase
   syntheses + 4 build retrospectives). The certificates prove the coursework happened; the
   corpus demonstrates what the learner can *see*.
